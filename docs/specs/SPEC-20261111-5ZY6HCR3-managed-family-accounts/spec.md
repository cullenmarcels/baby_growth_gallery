# 家庭专用账号与三级权限

- 用户名和密码登录。用户名支持汉字、ASCII 字母数字、短横线和下划线，NFC 规范化、ASCII 不区分大小写、全站唯一。关闭注册、验证码和邀请。
- 站点超管可开户、启停、重置、建空家庭和管理成员角色。家庭内容始终需要有效家庭成员关系。家庭角色为 ADMIN 或 MEMBER。建空家庭后先指定有效家管，已开放家庭至少保留一位。
- 家管在本家开户并自动入户，或按准确账户名添加已有账号。仅可移除普通成员。家管仅可重置自己在本家创建、只加入本家、仍是普通成员的普通站点账号。账号可原样保存当前密码并完成首次设置。沿用家管签发的密码时，仅可使用本家普通成员权限，改用不同密码后才可增加家庭或升为家管。
- 初始超管由部署端交互初始化。开户与重置一次性返回 24 小时有效的临时密码，首次登录改密并自行接受现行条款后进入业务。使用现有哈希、限流、CSRF、Origin 和服务端会话保护。修改凭据或停用撤销旧会话。
- 家庭活动、活跃家庭选择、宝宝与内容权限沿用既有契约中未被本修订变更的行为。多人家庭内容依家庭关系授权，多家庭独立授权。
- 旧数据不迁入。仅本地开发环境重建，先独立演练，再核对并备份本地数据目标后切换。

## 本地开发环境重建与回退

本地重建面向 Compose 项目 baby-growth-gallery。记录实际 PostgreSQL 数据库、MinIO 私有桶、Redis 项目前缀、挂载、镜像和宿主端口。PostgreSQL 实例可能包含其他数据库，清理只涉及已核对的应用数据库。Redis 清理只涉及已核对的应用会话键。

### 隔离演练

使用独立 Compose 项目、端口、数据库、照片桶和 Redis 前缀。运行 `pnpm --filter @baby-growth-gallery/api exec prisma migrate deploy`。端到端测试要求 `E2E_DATABASE_URL` 指向环回地址上的 `bgg_e2e_*` 数据库，容器回归另设 `STACK_BASE_URL` 与 `E2E_API_BASE_URL`。用测试账号跑完两级管理员开户和成员换密。

### 切换

1. 确认本地目标环境和操作者可交互初始化超管。停止目标应用和对照片桶的写入。
2. 用 PostgreSQL 自带的 `pg_dump -Fc` 备份应用数据库，保留照片存储的私有配置与对象。备份保存在仓库外的本机目录。将数据库和对象存储分别还原到隔离位置，核对记录与对象计数，记录备份哈希。
3. 准备空数据库，应用全部迁移。迁移遇到旧账号或家庭数据会停止，清理与迁移分开执行。切换时使用空的项目照片桶和独立 Redis 前缀，退役旧项目会话。
4. 用 `pnpm --filter @baby-growth-gallery/api super-admin create` 在交互终端设置首位超管。容器也可执行 `docker compose exec api node dist/auth/super-admin.js create`。由操作者输入账户名与隐藏显示的临时密码。超管丢失凭据时使用对应的 `reset` 命令。
5. 核对 API readiness、Web 页面、超管首次换密、家庭任命、家管开户和成员登录。切换验证成功后退役已备份的旧应用数据库和旧照片对象。

### 回退

切换验证失败时停止新版写入，恢复旧镜像和配置，将数据库和照片备份还原到原项目的对应位置，校验记录及对象计数。恢复旧版后旧账号重新登录。保留可恢复的离线备份用于人工核对。
