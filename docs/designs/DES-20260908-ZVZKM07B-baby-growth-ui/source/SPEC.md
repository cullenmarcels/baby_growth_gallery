# 小福宝成长记 · 前端开发规格（Codex Handoff）

> 本目录是把 Ardot 设计稿「翻译」给 Codex 的交付包。Codex 无法直接读取 `.ardot` 文件，
> 请让它按本规格 + `screenshots/` 视觉参考 + `tokens.*` 设计令牌来实现。

---

## 1. 项目概览

- **产品**：小福宝成长记 —— 宝宝成长记录与家庭共享的图集网站
- **视觉风格**：奶油暖阳（温暖、圆润、柔和橙色主调）
- **主色**：`#E8914A`（暖橙）｜ 强调 `#F2A08D`（珊瑚粉）
- **页面底色**：`#FBF4EC`（奶油米白）｜ **卡片**：纯白 `#FFFFFF`
- **字体**：Noto Sans SC（中文无衬线）
- **设备**：桌面端 1440 宽 + 移动端 375 宽，两套界面都要实现

## 2. 设计令牌（Design Tokens）

Codex 应先落地 `tokens.css` 中的 CSS 变量，全程用变量取色，**禁止硬编码色值**。

| 变量 | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#FBF4EC` | 页面底色 |
| `--color-primary` | `#E8914A` | 主按钮 / 高亮 / 选中态 |
| `--color-accent` | `#F2A08D` | 强调 / 渐变辅助 |
| `--color-card` | `#FFFFFF` | 卡片 / 导航栏底 |
| `--color-border` | `#F0E6DA` | 卡片描边 |
| `--color-border-light` | `#F2EADB` | 虚线框 / 次级描边 |
| `--color-text-strong` | `#4A3B2F` | 标题 / 深色文字 |
| `--color-text-default` | `#6B5A4A` | 正文 |
| `--color-text-sub` | `#9A8B7B` | 辅助 / 占位文字 |

**圆角**：卡片 `12~20px`（列表卡 12、大卡 20）、图标圆 `23px`、胶囊 `999px`
**阴影**：卡片 `0 8px 24px -8px rgba(233,145,74,.10)`
**间距栅格**：桌面内容区左右内边距统一 `64px`；移动端统一 `16px`

## 3. 字体与排版

- 标题：`Noto Sans SC` **Bold**，主标题 24–28、区块标题 18–20
- 正文：Regular/Medium 14–16
- 辅助/占位：12–13，颜色 `--color-text-sub`

## 4. 组件清单与 API（9 个）

Codex 应**先实现组件库，再做页面**。每个组件支持以下 props：

| 组件 | 关键 Props | 视觉要点 |
|---|---|---|
| **Navbar 导航栏** | 5 个链接文本（时间轴/图集/里程碑/成长数据/家庭） | 白底、高 72、左右内边距 64 |
| **ButtonPrimary 主按钮** | `label` | 橙底白字、圆角、hover 变深 |
| **ButtonSecondary 次按钮** | `label` | 白底 + 边框、深字 |
| **PhotoCard 照片卡** | `title`, `date`, `image` | 白卡、图片区 + 标题日期 |
| **MilestoneCard 里程碑卡** | `title`, `date` | 白卡、圆角 16 |
| **StatCard 数据卡** | `label`, `value`, `unit` | 右上图标、大数值 30 Bold、底部趋势条 |
| **Avatar 头像** | `image` | 渐变圆形 |
| **MobileTabBar 底部导航** | `active` | 移动端底部、5 tab、选中态主色 |
| **QuickEntry 快捷入口** | `title`, `subtitle`, `iconColor` | 白卡圆角 20、图标圆 + 文案 |

## 5. 页面清单

**桌面端（13 页，1440 宽）**
首页 / 时间轴 / 照片详情 / 图集 / 里程碑 / 成长数据 / 家庭空间 / 设置 / 个人信息 / 登录 / 注册 / 忘记密码 / 上传照片

**移动端（13 页，375 宽）**
首页 / 时间轴 / 照片详情 / 图集 / 里程碑 / 成长数据 / 家庭空间 / 设置 / 个人信息 / 登录 / 注册 / 忘记密码 / 上传照片

> 移动端统一结构：顶部栏（返回 + 标题）＋ 浅底内容区（16 内边距）＋ MobileTabBar 底部导航。
> 登录/注册/忘记密码/上传为流程页，无底部导航。

## 6. 响应式断点

- 桌面：`≥ 768px`，参考 1440 布局，内容区最大宽可设为 1440 居中
- 移动：`< 768px`，参考 375 布局，单列 + 底部导航
