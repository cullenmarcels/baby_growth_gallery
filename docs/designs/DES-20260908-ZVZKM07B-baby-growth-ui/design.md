# 小福宝成长记 UI 设计基线

## 适用范围与来源

本 Design 登记 `D:\codex-handoff` 的原始交付包，作为后续页面实现的视觉证据。原件保持在外部目录，项目内的 `source/` 是 2026-09-08 导入的只读语义快照；文件哈希、物理尺寸和导出比例见 `source-manifest.md`。

## 已确认基线

- 产品视觉方向为“奶油暖阳”：温暖、圆润、柔和橙色主调。
- 桌面参考逻辑宽度为 1440 px，移动参考逻辑宽度为 375 px；截图均为 2 倍导出，所以文件像素宽分别为 2880 px 和 750 px。
- 页面底色、卡片、文本、边框、圆角和阴影以 `source/tokens.css`、`tokens.json`、`tokens.scss` 为证据；运行时代码以 CSS Variables 为唯一消费接口。
- 原包包含桌面与移动各 13 个页面参考：主页、时间轴、照片详情、图集、里程碑、成长数据、家庭空间、设置、个人信息、登录、注册、忘记密码、上传照片。
- 本阶段只实现明确标识为“工程状态页”的连接验证界面，不把状态页冒充以上任何正式产品页面。

## 本阶段状态页约束

- 使用设计令牌形成克制的奶油暖阳视觉，不额外确认新的业务组件或页面结构。
- 覆盖 375、834、1440 三种视口，并验证加载、成功、错误三种连接状态。
- 文案固定为“正在连接服务”“前后端连接正常”“服务暂不可用”。
- 不使用真实宝宝照片、姓名、生日、手机号、成长数据或邀请码。

## 未定义项

- 834 px 平板的精确网格、间距和导航形态尚未由设计稿定义，只允许使用可适应布局，不登记为设计事实。
- 业务页面的空状态、加载状态、错误状态、交互动画、焦点流程、键盘行为和数据校验尚未定义。
- 设计截图中的照片和示例资料不是可交付真实资产；不得从截图反推或保存个人数据。
- 两档参考宽度之间的断点细节、正式 Web 字体加载策略和真实内容策略留给后续业务 Plan。
