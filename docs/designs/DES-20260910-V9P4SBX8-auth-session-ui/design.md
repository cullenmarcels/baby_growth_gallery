# 账号认证与会话界面补充设计

## 适用范围

本 Design 补充 `DES-20260908-ZVZKM07B` 中尚未定义的认证状态、平板布局、键盘和错误行为，不替代原有奶油暖阳令牌与 375/1440 截图。适用于登录、注册、找回密码、协议草案、受保护账号首页、404 和工程状态页。

## 响应式结构

- `>= 1024px` 使用桌面双栏：左侧品牌叙事与中性插画占位，右侧表单。
- `< 1024px` 使用单栏，保留品牌标题和副标题，移除大面积插图区。
- 验收视口固定为 375x812、834x1112、1440x1000；使用伸缩容器，不按设备名称硬编码。
- 所有页面无横向溢出；交互目标、错误摘要、密码显示和验证码按钮可使用键盘操作并具有可见焦点。

## 页面与交互

- `/login` 支持密码登录与短信验证码登录；不显示未实现的微信登录。
- `/register` 包含手机号、验证码、密码、协议与隐私草案确认。
- `/forgot-password` 包含手机号、验证码、新密码；成功后返回登录。
- `/app` 为受保护账号首页，展示脱敏手机号、会话状态和退出入口，不显示家庭或儿童数据。
- `/legal/terms`、`/legal/privacy` 明确标注为开发阶段草案，不表示可公开运营。
- `/system/status` 仅在显式启用时可见；其他未知路径显示产品化 404。

## 状态矩阵

- 表单：初始、字段错误、提交中、成功、网络错误、服务错误和重复提交防护。
- 验证码：发送中、60 秒倒计时、过期、尝试耗尽和限流。
- 会话：恢复中、已认证、未认证、过期和安全重定向。
- 错误使用字段提示与顶部摘要；动态消息使用 `aria-live`，焦点在提交失败后回到首个错误或摘要。
- 动画遵守 `prefers-reduced-motion`。

## 视觉与隐私

- 继续使用现有 CSS Variables，不在组件中硬编码项目颜色。
- 使用 Lucide 图标和中性渐变占位，不导入真实宝宝照片、姓名、生日、手机号、邀请码或成长数据。
- 桌面/移动“个人信息”语义冲突不在本 Design 解决；后续拆为成人账号与宝宝档案。
