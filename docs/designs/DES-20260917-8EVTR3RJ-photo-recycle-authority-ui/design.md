# 照片回收管理员优先的管理中心交互修订

除本文件明确覆盖的恢复入口与提示外，`DES-20260916-4XCFYD80` 的上传流程、管理中心、三视口布局、确认对话框和错误状态继续适用。

在 `/app/photos/manage` 中，管理员回收某成员照片后，该成员的“我的上传／回收站”仍保留只读卡片和 30 天清理日，恢复操作改为非交互说明“此照片不可自行恢复；若仍在恢复期，请联系家庭管理员。”本人以 MEMBER 身份回收且仍可恢复时，显示原“恢复”按钮。OWNER/ADMIN 在家庭回收站可恢复任意有效照片；不显示回收者身份、手机号或其他私密资料。

管理员本人看到不可恢复的过期照片时展示“恢复期限已过，无法恢复。”。若页面停留在旧状态，服务端 `PHOTO_RESTORE_ADMIN_REQUIRED` 拒绝操作后，页面以中文 `aria-live` 通知“需要家庭管理员恢复此照片”，刷新照片与家庭权限；不得自动重放 mutation。网络失败与未知错误仍使用中文兜底。按钮、说明、期限在 375／834／1440 均无横向溢出，移动底栏不遮挡卡片。权限提示为文本而非不可聚焦的假按钮，并保持可见焦点与 reduced-motion 行为。
