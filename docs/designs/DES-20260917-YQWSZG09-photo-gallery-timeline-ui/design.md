# 图集、时间轴、照片详情与头像选择界面补充设计

## 路由与结构

- `/app/gallery` 是当前宝宝的真实缩略图网格；`/app/timeline` 按拍摄年月分组显示照片，不渲染未创建的里程碑。切换家庭或宝宝后重新查询，避免短暂显示旧家庭图片。
- `/app/photos/:photoId` 是当前宝宝的照片详情；标题、描述、拍摄日、用户填写地点与安全 DISPLAY 图并列或上下排布。上一张/下一张沿列表顺序，边界禁用；加载失败提供返回图集入口。
- 已有顶部导航、宝宝切换器和移动底栏继续使用；图集/时间轴中的照片卡片可键盘进入详情。仅有 `canManage` 时显示编辑和回收，回收使用可访问确认对话框；失败后刷新页面数据并用中文 `aria-live` 提示。
- OWNER/ADMIN 在宝宝管理页选择或清除头像。选择器只展示当前宝宝已发布照片网格，不把管理中心草稿/回收站作为候选；保存后所有头像位置更新。其他成员可见头像但没有设置入口。

## 图像、状态与响应式

- 头像用安全缩略图 `object-fit: cover; object-position: center`，圆形裁剪；空头像和预览错误均回退到昵称首字。短时签名到期后可重取，不缓存到持久浏览器存储。
- 375、834、1440 三视口共同设计：图集随宽度变列、时间轴月份标题与卡片不溢出、详情大图保持比例且不遮挡操作、移动底栏不覆盖最后一行。
- 每页实现正常、空、加载、网络错误、无权/过期、照片回收后的旧链接状态；下一页失败保留已读内容并提供重试。使用既有 CSS 变量和图标，保留可见焦点、焦点恢复与 reduced-motion。
- 不出现评论、反应、视频控件或伪造的里程碑内容；全部可见错误使用稳定错误码的中文文案，图片 alt 以标题或“家庭照片”兜底。
