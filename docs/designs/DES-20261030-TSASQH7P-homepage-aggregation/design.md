# 宝宝首页数据聚合界面设计

## 适用范围

适用于已有 `/app/home` 宝宝首页。继承 [DES-20260915-S2PV4FM8](../DES-20260915-S2PV4FM8-baby-growth-mvp-ui/design.md) 的暖色视觉令牌、桌面导航、紧凑顶部栏、移动底部导航和可访问性约束。本 Design 只增加首页真实数据摘要，不重新设计导航壳和各功能详情页。

## 页面层级

- 保留宝宝头像、昵称、年龄/性别信息和档案管理入口。
- 头部下依次展示最新照片、里程碑进度、近期提醒、最新成长数据。
- 桌面使用内容自适应的卡片网格；平板和移动端按单列顺序排列，窄屏不得产生横向滚动。
- 每个区块使用清晰标题、摘要内容和对应功能页入口。空、加载或错误只影响所属区块。

## 区块交互

- 照片卡展示最多 3 张真实已发布缩略图；缩略图有可访问名称并各自进入照片详情，区块入口进入完整图集。
- 里程碑进度以已完成数/总数呈现并可进入清单。
- 提醒按日期升序最多展示 3 项；每项显示标题和提醒日期并进入详情。没有 30 日内提醒时显示简洁空状态及清单入口。
- 成长摘要按身高/身长、体重、头围、BMI 展示最新值和日期；可用时附百分位，不以颜色单独表达参考信息；区块入口进入成长数据页。
- 每个加载状态提供稳定占位；每个错误区块展示中文说明和独立重试操作；空区块提供对应现有入口。

## 响应式与可访问性

- 验证 375、834、1440 宽度；沿用既有断点及 `>=1024px` 桌面导航、`<1024px` 紧凑导航规则。
- 页面内容不得被移动底栏遮挡。缩略图、摘要入口、提醒链接和重试操作键盘可达，焦点可见，名称与状态可被辅助技术识别。
- 使用现有 CSS Variables、间距、圆角、阴影与 Lucide 图标；不新增图表库、颜色体系或动效偏好。
- 保留站点现有中文错误映射、`aria-live` 状态提示和 `prefers-reduced-motion` 行为。
