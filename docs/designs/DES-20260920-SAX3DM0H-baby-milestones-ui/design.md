# 成长里程碑、提醒与混合时间轴界面设计

## 页面结构

- `/app/milestones` 使用真实数据展示“已完成 X / Y 项”、今天及未来提醒、最近完成项，以及“清单／已完成”列表。总数为 0 时显示明确空状态，不渲染示例数据或虚假比例。
- `/app/milestones/new` 使用可访问的“模板／自定义”切换。模板卡显示 12 项固定标题，已加入项禁用；自定义表单包含标题和可空提醒日期。
- `/app/milestones/:milestoneId` 展示标题、来源、创建者、提醒、完成信息和最多 10 张安全缩略图。只在 `canManage` 时显示编辑、完成、撤销和移出操作。
- 时间轴继续按年月分组。里程碑卡展示标题、日期和可空说明摘要，进入里程碑详情；照片卡保持 Plan E 行为。

## 交互与状态

- 未完成项提供“完成”“编辑”“移出清单”；已完成项提供“编辑”“撤销完成”“移出清单”。完成表单包括完成日期、说明和照片选择器。
- 照片选择器只读取当前宝宝的 PUBLISHED 照片，显示选择数量和 10 张上限，保持 API 顺序及短时 THUMBNAIL 预览；图片失败可重取签名，不隐藏正文。
- 已完成项移出前确认；对话框打开后聚焦标题或首控件，Escape 关闭，关闭后恢复触发按钮焦点。表单错误汇总与异步状态使用中文 `aria-live`。
- 页面覆盖初始加载、空列表、网络错误、下一页错误、只读、权限变化、版本冲突、详情失效和照片预览失效。旧页面失败后刷新数据与权限，不自动重放写操作。

## 响应式与视觉

- 沿用奶油暖阳 CSS Variables、现有卡片、圆角、阴影、顶部导航与移动底栏。
- 1440：桌面概览区与多列卡片；834：两列自适应卡片并堆叠概览；375：单列卡片，内容底部留出导航安全空间。
- 说明正文允许换行，标题安全截断；操作按钮始终单行，同场景同级按钮以 44px 为基准等高。新增操作文案均不超过五个中文字符。
- 支持可见焦点、键盘操作、语义化日期、图片 alt 和 reduced motion；不使用颜色作为唯一状态信号。
