# 家庭专用登录和管理界面

- 登录页使用账户名与密码。换密页提供当前密码、新密码及初次条款确认，保存和退出按钮纵向排列，间距为 12px。无家庭时展示等待分配与退出入口。
- /admin 默认跳转 /admin/members。深色侧栏包含成员管理和家庭管理。浅色工作区顶部包含当前模块和账户菜单，可返回家庭空间、修改密码和退出登录。1024 像素起显示侧栏，低于该宽度通过导航按钮打开侧边菜单。620 像素及以下将表格行显示为带字段标签的卡片。
- /admin/members 列出账户名、显示名和启停状态，按账户名或显示名搜索，支持启用和停用筛选。新建成员使用弹窗，成功后在列表当次显示临时密码。列表提供详情、密码重置和启停。成员详情显示家庭关系及角色，并可进入对应家庭详情。
- /admin/families 列出家庭名称、开放状态和成员人数。新建家庭在弹窗提交，列表显示待开放。/admin/families/:familyId 可直接打开和刷新，支持添加已有账号、指派首位家管、任免及移除成员。
- 两个列表每页 20 条，搜索、状态和页码用 q、status、page 记录在 URL。打开详情时携带当前列表参数，返回恢复原列表。成员管理负责账户级操作，家庭管理负责家庭内分配和角色调整。
- /app/families/:familyId/manage 为本家家管提供开户、已有账号入户、成员移除和合格账号重置。家庭详情显示成员和动态，家管可进入管理。
- 临时密码仅在操作成功后当次显示，切换上下文时销毁展示。各管理页有加载、空、错误、成功、提交中状态，使用既有字段、焦点、按钮和确认对话框习惯，在 375、834、1440 像素验证。
