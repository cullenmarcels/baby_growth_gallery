# 成长数据界面设计

沿用 DES-20260908-ZVZKM07B 与 DES-20260915-S2PV4FM8 的暖色令牌、Lucide、导航和 >=1024px 桌面布局。
桌面概览横排、曲线与记录卡片；834/375 自适应纵向布局。有效/回收站切换、指标切换、日期范围、分页操作等高单行。新增/编辑独立表单，回收与彻底删除使用可访问确认对话框。参考不可用解释原因，记录者和每项测量日期可见。
正常、空、加载、错误、权限、冲突、到期和生日冲突均有中文反馈；支持键盘、焦点恢复和 reduced-motion。SVG 提供图例、单位和文本记录，不使用示例曲线冒充真实数据。
