# 照片卡片与详情上传者、来源导航

## 卡片与详情信息层级

- 图集/时间轴照片卡片保持标题、拍摄日期、上传者的顺序；上传者置于日期下方、靠右、单行，延续现有卡片尺寸、链接可访问名称、焦点和键盘行为。超过 15 个 Unicode code point 的名称仅在卡片视觉文案中截断为前 15 个字符加 `…`，辅助信息保留全名。
- 照片详情在标题区之后、查看/编辑内容之前放置只读上传者行，明确标为“上传者：姓名”。详情名不采用卡片的 15 字截断规则；允许自然换行，避免窄屏溢出，并在编辑模式下仍然可见。
- 里程碑详情的关联照片呈现保持不变。

## 来源返回

照片详情页顶部返回控件按已验证来源显示“返回图集”“返回时间轴”或“返回里程碑”，目标为对应固定应用路由。详情加载、错误和照片失效状态也保留来源返回控件。上一张/下一张继续按服务端顺序排列并携带相同来源。无效上下文回退到图集。

## 响应式与可访问性

在 375×812、834×1112、1440×1000 检查图集、时间轴、里程碑关联照片和照片详情。上传者不得产生水平滚动；长详情名称可换行；返回及相邻照片链接的焦点可见、Tab 顺序不变。
